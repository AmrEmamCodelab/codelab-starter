# starter-web

The starter's Angular 22 frontend. Start with [MODULE.md](MODULE.md) for the layout, commands and rules, and with
[src/app/core/MODULE.md](src/app/core/MODULE.md) for the services every screen uses.

Quick start (from the repo root, with Node 24.15 or newer on `PATH`):

```powershell
npm install
npm start --workspace frontend/starter-web   # http://localhost:4280, API expected on http://localhost:5180
```

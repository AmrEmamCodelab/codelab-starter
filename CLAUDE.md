# CLAUDE.md

`codelab-starter` is Codelab's forkable starter for Ministry and KSA-government request portals: .NET 10 backend, Angular 22 frontend (Arabic-first, RTL, DGA look), IIS and SQL Server on premises. A versioned security core ships as `Codelab.*` NuGet and `@codelab/*` npm packages; everything else is source that each project forks and renames (ADR-000, ADR-003).

- **Read [CONTEXT.md](CONTEXT.md) first:** repo map, glossary, module index, commands and use-case tracing.
- **Load the `coding-standards` skill** ([docs/standards/SKILL.md](docs/standards/SKILL.md)) before any implementation (feature, bug fix, refactor) and before any review. Implement to it and review against it.
- **Rules are enforced by CI.** `tools/build.ps1 -Target CI` is the authoritative gate; Claude hooks only warn early (ADR-006). Work is not done until CI is green.

## Non-negotiable rules

1. **Starter names only.** `Starter.*` projects, `Codelab.*` / `@codelab/*` packages. No names from the harvest source; the scrub sweep fails the build (`docs/adr/` and `provenance/` are the only exceptions).
2. **No secrets or key material** in the repo. Never read `*.pfx` or `*.key`. Keys are generated by `init.ps1`, never copied.
3. **Time comes from `TimeProvider`.** `DateTime.Now`/`UtcNow`/`Today` and `DateTimeOffset.Now`/`UtcNow` are banned APIs (build error RS0030).
4. **Enums are stored as integers** with an explicit value on every member; no `HasConversion<string>()` on enums.
5. **No magic strings or numbers.** IDs, permission/role/config/claim/route/cache/job keys, error codes and limits come from typed constants or options. Lookup IDs come from the module's constants class.
6. **Named arguments** for calls with two or more same-type parameters.
7. **Unit tests are mandatory** for every use case, validator, transition, domain rule and frontend service or component with logic, in the same change.
8. **Thin edges.** Controllers and components hold no business logic; no `DbContext` in the Api layer; Application depends on ports only. Every endpoint has `[HasPermission]` (or is allowlisted as anonymous), PublicId route IDs, a validator and problem+json errors.
9. **Frontend.** HTTP only through `ApiService`. UI only from `@codelab/ng-dga` and the 8 page patterns; no other UI library and no external DGA package. No raw text: every string has `ar` and `en` keys. Design tokens and logical CSS only. Routes and action buttons are gated by permission keys.
10. **Lookups are seeded only by migrations.**
11. **Generated files are never hand-edited:** `rules/rules.compiled.json`, nested module `CLAUDE.md`, `BannedSymbols.generated.txt`, `docs/generated/`. Change the source and rerun the generator.
12. **Docs move with code.** A module change updates its `MODULE.md` (Purpose, Use, Extend, Rules, Gotchas), or the commit message or PR description carries `Docs-Not-Needed: <reason>`.
13. **Platform-owner review** for `rules/`, `packages/`, `.claude/`, `**/module.rules.yaml` (its `exemptions`), `deploy/`, `.github/`, `docs/adr/`, `provenance/`, `docs/standards/`, `tools/extract/`, `tools/build.ps1`, the frontend lint configs (`eslint.config.mjs`, `stylelint.config.mjs`, `tools/lint/`) and the build settings at any depth (`.editorconfig`, `Directory.Build.*`, `Directory.Packages.props`, `nuget.config`, `global.json`) (CODEOWNERS; the hooks refuse these edits without `CODELAB_PLATFORM_OWNER=1`).
14. **Central package versions.** Never put a `Version` on a `PackageReference`; pin it in `Directory.Packages.props`.

## Build

```powershell
# Full CI contract (18 steps); add -FailFast to stop at the first failure, -BaseRef <ref> to set the base branch
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build.ps1 -Target CI
# Pack every package in packages/versions.json as <version>-ci.<n> prereleases into feed\nuget and feed\npm
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build.ps1 -Pack
# Release the exact versions (platform owner only; packs after a green CI, refused when a version is in the feed)
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build.ps1 -Target CI -Pack -Release
# Local stack: API :5180, Attachment service :5185, web :4280 (+ Seq :5341 when available); -NoAttachments skips the service; -Stop stops only what it started
powershell -NoProfile -ExecutionPolicy Bypass -File run-local.ps1
# Local secrets for the API and the Attachment service (gitignored appsettings.Development.local.json; adds missing keys, -Force regenerates)
powershell -NoProfile -ExecutionPolicy Bypass -File tools\devseed\New-LocalSecrets.ps1
```

**dotnet is private on this machine.** The .NET 10 SDK (10.0.403, pinned in `global.json`) is at `E:\codelab-tools\dotnet10\dotnet.exe` and is **not on PATH**; the `dotnet` on PATH is .NET 9 and cannot build this repo. Invoke that exe directly, or set `$env:CODELAB_DOTNET`. `build.ps1` resolves `CODELAB_DOTNET`, then that path, then `dotnet` on PATH. Details: [tools/README.md](tools/README.md).

Decisions live in [docs/adr/](docs/adr/README.md). The build plan and the decision log are platform-team inputs kept outside this repository (every fork would inherit them); what they decided is recorded in the ADRs.

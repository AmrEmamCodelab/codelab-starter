# Generated docs

> Generated by `backend/tools/Starter.DocsGen`. Do not edit; regenerate with `dotnet run --project backend/tools/Starter.DocsGen -- --out docs/generated`.

Every file in this folder is generated from the code by `backend/tools/Starter.DocsGen`, which starts the
API host in-process (Development, no database) and reads its modules by reflection. Never edit a file here:
change the code, then regenerate. CI fails when a file drifts from the code.

| File | Content |
| --- | --- |
| `openapi.v1.json` | The OpenAPI document `v1` (normalized: no `servers`, sorted paths and components). Input of the frontend client. |
| `permissions.json` | The permission catalog, `{permissions:[{key, module, description}]}`. Input of the frontend `PermissionKeys`. |
| `permissions.md` | The permission catalog with the endpoints each key guards. |
| `endpoints.md` | Every endpoint: method, route, permission or allowlisted access, owner, summary. |
| `error-codes.md` | Every `*ErrorCodes` constant, by owner. |
| `config-keys.md` | Every configuration key of every options class with a `SectionName`. |

Commands (from the repository root; the .NET 10 SDK is private on the build machine, see `tools/README.md`):

```powershell
# regenerate this folder
dotnet run --project backend/tools/Starter.DocsGen -- --out docs/generated
# fail (exit 1) and list the drifting files when this folder does not match the code
dotnet run --project backend/tools/Starter.DocsGen -- --out docs/generated --check
# then regenerate the frontend client and permission keys from openapi.v1.json and permissions.json
npm run api:gen --workspace frontend/starter-web
```

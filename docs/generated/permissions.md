# Permissions

> Generated by `backend/tools/Starter.DocsGen`. Do not edit; regenerate with `dotnet run --project backend/tools/Starter.DocsGen -- --out docs/generated`.

The permission catalog: the union of every module's `IPermissionCatalogSource`. Each key is a constant of its module's `<Name>PermissionKeys` class; the frontend's `PermissionKeys` is generated from `permissions.json` (`npm run api:gen`). The break-glass account holds every key; nobody else holds a key until it is granted.

# Release notes: v1.0.0 (unreleased draft)

## What ships

- **Packages at 1.0.0** in `feed/`: `Codelab.Build.Sdk`, `Codelab.Security`, `Codelab.Observability`, `Codelab.Errors`, `Codelab.Integration`, `Codelab.Identity`, `Codelab.Testing`, `@codelab/ng-security`, `@codelab/ng-dga`, `@codelab/ng-tools`. Changes per package: [packages/CHANGELOG.md](../../packages/CHANGELOG.md).
- **The starter source:** backend kernel and modules, the Angular app, the attachment service, integration gateway and Ops Console, deploy and handover kits, runbooks, and the AI kit. Summary per phase: [CHANGELOG.md](../../CHANGELOG.md); repo map: [CONTEXT.md](../../CONTEXT.md).
- **Fork path:** `init.ps1` → `run-local.ps1`; later starter releases come in through `tools/upstream-merge.ps1`.

## Known open items

- The full `tools\build.ps1 -Target CI` and the preset matrix (all, core only, SSO only) did not run inside phases 6 to 10 (owner decision); they must be green before the tag.
- External security review (A6) not done: the risk acceptance in [ADR-013](../adr/ADR-013-external-review-risk-acceptance.md) is Proposed and waits for the owner decision.
- [ADR-009](../adr/ADR-009-font-and-icon-licences.md) (font and icon licences) is still pending owner approval; DoD requires every ADR to be final before the tag.
- [ADR-010](../adr/ADR-010-migration-squash.md): the permission catalog is filled at runtime by `PermissionSynchronizer`, not seeded by `InitialCreate`; owner approval of this deviation is open.
- No Playwright smoke has run in CI, no preset-matrix leg has run, and the upstream-merge exit test (`tools/fork/tests/upstream-merge-exit.e2e.test.mjs`) still uses a synthetic starter with a marker-file build, not the real tree with `dotnet build -warnaserror` + tests. CHANGELOG.md therefore keeps 1.0.0 under [Unreleased] with no date, and the 1.0.0 pins in packages/versions.json are provisional until those legs are green.
- Package validation has no baseline yet: set `CodelabPackageBaselineVersion` to 1.0.0 in each package before the first patch release.
- P4: design-agent proof evidence (diff target), ng-dga icon-font double download, visual baselines re-run.
- P3: last-manager guard opt-in and the default grant scope (Global or own organization) are owner decisions.
- Playwright is driven through MCP, not a CI suite.
